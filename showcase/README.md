# LargePDF by xCC — Showcase & Landing Page

This folder contains the complete, standalone, production-ready showcase landing page for **LargePDF by xCC** (100% Private, Uncapped Browser PDF Studio).

## 🚀 How to Use & Open

### Option 1: Open Locally in Any Browser
Simply double-click `index.html` or drag it into any web browser (Chrome, Firefox, Safari, Edge, Brave).  
All assets, scripts, and fonts work out-of-the-box.

### Option 2: Deploy to Any Static Web Host
You can drag and drop this entire unzipped folder into any static host:
- **Cloudflare Pages**: Link repo or direct upload
- **Vercel / Netlify**: Drop folder for instant CDN deployment
- **GitHub Pages**: Push to `gh-pages` branch
- **Apache / Nginx / ByetHost**: Upload to your `public_html` directory

## 📁 Included Assets
- `index.html`: Responsive single-page showcase with interactive feature tabs, live 21-tool directory with instant search & category filters, architectural comparison diagram, interactive network payload simulator, FAQ accordion, and dual CTAs.
- `images/`: High-resolution documentary workspace photography for tools (compression, merge, organize, stamp, typewriter conversion, sign contract, and privacy desk).
